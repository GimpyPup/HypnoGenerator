Programming Instructions:
  • Script format: Enter one command per line. Each command will be processed with layered repetition for deep programming.
  • Default interval: The standard pause between commands (configurable above). Custom delays override this setting.
  • Carrier signal: Duration of the underlying binaural frequency before and after your programming sequence.
  • Internal notes: Lines beginning with # are ignored by the system. Use for your own reference:# Deepening sequence begins
  • Timed delays: Prefix [5] to insert a 5-second processing pause before execution. Example:[3] Obedience is pleasure
  • Repetition cycles: Use [x3] to loop a command 3 times for reinforcement.
  • Combined directives: Chain delay and repetition tags to script more complex responses. Example:[2][x5] Unit compliesSpeaks “Unit complies” five times with a 2-second pause between each repetition.
  • Block definition: Wrap lines in [BLOCK:name] and [/BLOCK:name] to create a repeatable block. Add [x3] and delay tags on the opening line. [BLOCK:mantra][x3][5] You are going deeper Relax and obey [/BLOCK:mantra] Speaks both lines 3 times with 5-second gaps between passes.
  • Block replay: Reference a defined block later to replay it: [BLOCK:mantra][x2] Replays the block's current contents twice.
  • Silent definition: Use [x0] to define a block without playing it: [BLOCK:intro][x0] The block is defined but won't play until referenced.
  • Nesting: Blocks can be nested up to 3 levels deep. Deeper nesting is flagged in the editor.

Remote Control Options

This page listens on a BroadcastChannel named hypno-control. Any page on the same origin can send commands to control playback and settings. Open a browser console on another tab and send messages like:

new BroadcastChannel('hypno-control').postMessage({ action: 'start' })

new BroadcastChannel('hypno-control').postMessage({ action: 'setInterval', value: 5 })

ActionValueEffect
start-Start playback
stop-Stop playback
pause-Toggle pause
setScriptstringReplace the editor content
setIntervalnumber (seconds)Set the default interval
setCarrierSignalnumber (seconds)Set the carrier signal duration
setCarrierFrequencynumber (Hz, 75-200)Set the carrier frequency
setVoiceSpeednumber (-0.5 to 0.5)Set the voice speed offset
